# NuVerter Handoff — 2026-11-07

## What's Done (v1.1.36)

### OCR Fixed (Desktop + Mobile)
- **Root cause**: Tesseract.js ESM export (`tesseract.esm.min.js`) only exposes a `default` property. Old code read `mod.createWorker` → `undefined` → every OCR run crashed.
- **Fix**: `getTesseractLib()` now unwraps `mod?.default?.createWorker ? mod.default : mod`.
- **Language packs**: Switched from `tessdata.projectnaptha.com` (no CORP header, blocked by app's `COEP: require-corp`) to jsDelivr `@tesseract.js-data/<lang>@1.0.0/4.0.0_best_int` which sends `Cross-Origin-Resource-Policy: cross-origin`.
- **Mobile images**: Added `prepareOcrImage()` — downscales phone photos (often 12 MP+) to `maxSide = 2400` before recognition to avoid OOM and long runs.
- **Progress + errors**: `ocrImage(file, lang, onProgress)` helper with logger, visible `.util-error` output in UI.
- **All 3 call sites updated**: Utility OCR, Document Indexer OCR, Workflow OCR node.
- **Verified in browser** at `http://localhost:4173`: 95% confidence on test canvas, COI `true`, loads language pack on first run.

### AI Chat Tool-Calling Fixed
- **Missing model mappings**: Added 16 `tool-*` entries to `AI_CHAT_MODELS` (were missing, fell back to `tiny`).
- **Tool name mismatch**: Renamed `search_web` → `web_search` in `AI_CHAT_TOOLS`; handler accepts both.
- **Conditional system prompt**: Tool-capable models now told "You can call these tools… Never say you are unable to use tools." Non-tool models told they cannot call tools directly.
- **`max_tokens`**: 256 → 1024 (both streaming + tool first call).
- **Vision tool models**: Fixed `tool-vision-1/2/3` — labeled "Vision only", `tools: false` in UI (they don't support function calling).
- **All 8 tools handled**: `web_search`, `fetch_url`, `open_tool`, `list_tools`, `get_queue_status`, `clear_queue`, `get_history_count`, `set_theme`.
